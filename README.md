# Week 1 – Data Acquisition and Pre-processing in Python

## Internship Task

This project demonstrates a complete data acquisition and data pre-processing workflow using Python.

## Dataset

**UCI Student Performance Dataset – Mathematics**

The dataset contains academic, demographic, and social information about students and is publicly available through the UCI Machine Learning Repository.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn

## Pre-processing Steps

1. Data acquisition and loading
2. Data inspection
3. Missing-value checking and treatment
4. Duplicate removal
5. Outlier detection using IQR
6. Categorical encoding
7. Feature standardization
8. Data visualization
9. Export of cleaned dataset

## Project Files

* `week1_student_performance_preprocessing.py` – Main Python preprocessing script
* `student-mat.csv` – Original dataset
* `student_performance_cleaned.csv` – Processed dataset
* `outlier_boxplot.png` – Outlier visualization
* `correlation_heatmap.png` – Correlation visualization

## Objective

The objective of this project is to understand and implement the basic data acquisition and preprocessing workflow required before performing data analysis or machine learning.

## Outcome

A structured preprocessing pipeline was developed to improve data quality and prepare the dataset for further exploratory data analysis and machine learning applications.
